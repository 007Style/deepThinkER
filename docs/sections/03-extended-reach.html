03 — Extended Reach · Internet Access

The defining feature of deepThinkER is its name: Extended Reach. For the first time, these locally-running AI personalities can reach out and touch the live internet — searching DuckDuckGo, fetching pages, pulling in real-world information mid-conversation. But this power comes with a leash: the Trust System.

What "Extended Reach" actually means: Each character can embed tool-call tags in their responses. When the ToolCallInterceptor detects one, it executes the tool, injects the result back into the character's context as a system message, and the character continues their response informed by the fresh data. The whole thing happens in real time, mid-stream.

How It Works — The Tag Syntax

Characters request internet access by embedding plain-text tags directly in their responses:

// Web search [SEARCH: benefits of large language model ensembles] // Direct URL fetch (whitelist-checked) [FETCH: https://arxiv.org/abs/2405.12345]

These tags look like plain text to the model — no special prompt engineering required. The ToolCallParser scans every completed token chunk for these patterns using a simple regex pass. When one is found, the interceptor takes over.

The Request Pipeline

Step 01
Character Requests
Character embeds [SEARCH: …] or [FETCH: …] in their streamed response
Step 02
Trust Check
Interceptor checks character's current trust tier. Below Low tier → request denied and logged
Step 03
Rate Check
Sliding-window rate limiter checks per-character and global caps. Violation → deny + trust penalty
Step 04
Execute
DuckDuckGo HTML search or URL fetch (whitelist-checked). Result is cleaned and truncated
Step 05
Inject & Log
Result injected as a system message. Logged to audit log. UI badge lights up on character's panel

The Search Badge

When a character performs a live web search, a LIVE badge appears on their quadrant header in real time. Clicking or expanding it reveals the full search result that was injected into the conversation. The complete network log for the session is also available under Settings → Network.

Proactive Search Injection

deepThinkER also includes a ProactiveInjector — a background component that analyses the conversation topic and can pre-emptively inject relevant context into a character's system prompt before they even ask. Think of it as giving the characters a heads-up: "Hey, this conversation is heading towards quantum computing — here are some recent headlines." This is always presented as injected context, never as a character's own words.

DuckDuckGo — Why Not a Search API?

deepThinkER uses DuckDuckGo's HTML endpoint rather than a paid search API (Google, Bing, Brave, etc.) for a deliberate reason: zero API keys, zero accounts, zero cost. The HTML scraping approach is entirely free, requires no registration, and aligns with the project's core philosophy of running without any external service dependencies. The trade-off is that result quality and rate limits are governed by DuckDuckGo's HTML interface rather than a dedicated API — but in practice it works extremely well for the kinds of real-time fact queries the characters make.

Privacy note: [SEARCH:] and [FETCH:] calls are the only moments when any data leaves your machine. The query text and fetched URL are the only things transmitted — no conversation history, no user data, no telemetry. Every outbound call is logged in the audit log so you always know exactly what was sent.
