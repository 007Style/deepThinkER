19 — Roadmap

deepThinkER is under active development. The roadmap below reflects planned features in rough priority order. Contributions toward any of these are welcome — see the Contributing section for how to get involved.

v1.0
deepThink — The Foundation
Four local AI personalities, 2×2 conversation grid, bundled Ollama runtime, streaming inference, jitter mechanics, context window management.
Released
v1.1
Extended Reach — Current Release
Trust-gated internet access, nine-tool framework, persistent character memory, dynamic mood system, relationship matrix, autonomous research mode, session analytics, full audit log, vision/image analysis, injection guard, content filter.
ReleasedmacOS
v1.2
Character Flexibility
Hot-swap characters mid-session without losing conversation history — swap in a different model or persona while keeping the full context intact.
Whisper mode — private messages to a single character that the others don't see, enabling sidebar conversations and secret context injections.
PlannedmacOS
v1.3
Shell Tool & Custom Characters
Shell tool (controlled command execution with a configurable allowlist) — the stub becomes real.
Custom character editor UI — create and save completely new personas with custom names, avatars, models, and prompts from within the app.
PlannedmacOS
v1.4
Windows Binary Release
A native Windows build. The core is already pure Dart — the work is in the Windows-specific Ollama bundling, entitlements, and installer packaging.
PlannedWindows
v2.0
Multi-Session Workspace & Memory Federation
A persistent workspace that spans sessions — characters carry forward not just their private memory but a shared project context. Cross-session memory federation: characters can reference what they learned in previous research sessions. Workspace-aware tool access with project-scoped permissions.
FutureAll platforms

Have a feature idea that's not on the roadmap? Open a Discussion on GitHub. The best feature requests come with a clear use case — describe what you're trying to do, not just what you want the app to do.
