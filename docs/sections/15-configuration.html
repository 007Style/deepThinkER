15 — Configuration

deepThinkER is configured at two levels: per-session settings in the Startup Config screen (which you see every time you start a conversation), and persistent global settings in the Settings screen (which carry across sessions). Between the two, nearly every aspect of the app's behaviour is configurable.

Startup Config Screen (Per-Session)

This screen appears before every conversation. Changes here apply only to the upcoming session, except for prompts and persona which are saved as defaults.

Per-Character Settings

  • Model — Select any locally installed Ollama model. Not limited to the defaults.
  • Master Prompt — Full control over the character's personality and base instructions. "Reset to Defaults" restores the curated IBM-character prompts.
  • Network Access — Toggle internet access on/off per character for this session.
  • Session Name — Auto-generated (e.g. "amber-koala-7") or customise it before starting.

User Persona

  • A free-text description of yourself — injected into every character's system prompt. They can use it to tailor their communication style and address you by name.
  • Examples: "I'm a software engineer who prefers precise technical language", "I'm a student exploring philosophy, please don't dumb it down"

Global Settings (Persistent)

🌐 Network Tab

  • Per-character network enable/disable (persists between sessions)
  • Global rate limit cap — searches/minute across all four characters (default: 10)
  • Domain whitelist — restrict [FETCH:] calls to specific domains
  • Network request log — view all search/fetch calls made this session

🔧 Tools Tab

  • Enable/disable individual tools (any of the nine can be blocked)
  • Workspace path — the directory FileReadTool and FileWriteTool operate within
  • Vision model selection (default: llava:7b)

🛡️ Safety Tab

  • Content filter — category keyword lists with configurable replacement text
  • Injection guard toggle — scans user input for tool-call tag patterns before injection
  • Domain whitelist management (add/remove/export)

🎨 Display Tab

  • High contrast mode — higher contrast text and borders for accessibility
  • Reduced motion mode — disables animations (respects macOS system preference too)
  • Font size scale — small / normal / large
  • Sound cues — enable/disable audio feedback on conversation events
Settings persistence: All global settings are saved to ~/Library/Application Support/deepThinkER/settings.json. This is a plain, human-readable JSON file — you can hand-edit it if needed.
Character prompts are powerful. Each character's master prompt is the single most impactful thing you can change. A well-crafted prompt for a domain-specific character (e.g., "You are a sceptical medical researcher…") will produce far more useful conversations than any configuration setting. Experiment freely — the Reset to Defaults button is always there.
