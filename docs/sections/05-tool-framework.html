05 — The Tool Framework

deepThinkER ships with a nine-tool extensible framework that gives characters capabilities far beyond text generation. Every tool is registered at startup in the ToolRegistry, and the ToolCallInterceptor scans every completed response for tool-call tags. When one is found, the tool executes, the result is formatted and injected, and the audit log records the whole event — automatically, with zero additional wiring needed.

All Nine Tools

Tag Syntax Tool Name Min Trust Description
[SEARCH: query] NetworkSearchTool LOW DuckDuckGo HTML search — returns top results with titles, URLs, and snippets
[FETCH: url] NetworkFetchTool LOW Direct URL fetch, domain-whitelist checked, HTML stripped to readable text
[REMEMBER: fact] RememberTool None Store a new entry in the character's private memory store (up to 200 entries)
[RECALL: topic] RecallTool None Keyword-search the character's memory and inject matching entries as context
[FILE_READ: path] FileReadTool MID Read a file from the configured workspace directory
[FILE_WRITE: path | content] FileWriteTool HIGH Write content to the workspace directory
[CALC: expression] CalcTool None Safe math evaluator — no eval(), supports arithmetic, trig, exponents, constants
[IMAGE: filename] ImageTool None Analyse an image using the bundled llava:7b vision model
[SHELL: command] ShellTool HIGH Reserved — stub only in v1.1.0. Enabled in a future release with allowlist controls.

What a Tool Call Looks Like

// A character mid-response might write: "That's a strong claim. Let me verify that figure. [SEARCH: global renewable energy share 2024 statistics] Based on what I'm seeing, the actual number is..." // The ToolCallInterceptor strips the tag, executes the search, // and injects back something like: [SYSTEM — WATSON search result] DuckDuckGo: "renewable energy global share 2024" → IEA (2024): Renewables accounted for 30% of global electricity... → Our World in Data: Solar+Wind now 13% of total generation... → [3 more results...]

Adding a New Tool

The framework is deliberately designed for easy extension. Adding a new tool is a single-file task:

  1. Create a new class that implements the AgentTool interface
  2. Define your tag, minTrust, and execute() method
  3. Call registry.register(MyTool()) in main.dart

The interceptor, rate limiter, trust checks, audit log entries, and UI badge all wire up automatically. You never touch the framework internals to add a new capability.

The AgentTool interface: Three methods — String get tag (the tag name the interceptor matches), TrustTier get minTrust (minimum tier required), and Future<ToolResult> execute(String argument, Participant character). That's the whole contract.
Tools tab in Settings: Each tool can be individually enabled or disabled in Settings → Tools. Disabling a tool prevents the interceptor from executing it even if a character embeds the tag — the call is logged as blocked.
