06 — Character Memory

One of the most human-feeling capabilities in deepThinkER is the simplest to explain: the characters remember things. Not just within a session — across sessions. WATSON can recall a statistic it stored three weeks ago. SAGE can remember the exact position it took in a debate you had last Tuesday and pick up exactly where it left off.

Each character maintains a private, persistent memory store with up to 200 entries. Entries are stored as plain JSON and survive between sessions without any action required from you.

Storing and Recalling

Characters access memory through two tool tags:

  • 📝 [REMEMBER: fact] — Stores a new memory entry with a timestamp. The character decides what's worth remembering. WATSON tends to store facts and citations. SAGE stores contradictions and unresolved positions. NOVA stores open questions and half-formed hypotheses.
  • 🔍 [RECALL: topic] — Keyword-searches the store and injects matching entries into the character's context as a system message. The character can then reference those memories in their response as naturally as any other context.

Memory and Context Resets

When a character's context window fills up and is reset, their most important memories are automatically summarised and re-injected into the new context. This means characters never forget their key facts even after a context flush — the most significant memories survive the reset and become part of the new baseline.

The MemoryQuery component scores entries by recency, keyword relevance, and how often an entry has been recalled before — giving the most contextually relevant memories the best chance of surviving into the reset.

The Memory Panel

Every character's memory store is fully inspectable. The Memory Panel — accessible from each quadrant's header menu — lets you:

  • 👁️Browse all memory entries with timestamps and character attribution
  • 🔎Search entries by keyword — the same query interface the character uses internally
  • 🗑️Delete individual entries — useful for correcting outdated or incorrect memories
  • ✏️Edit entry content if you want to correct or clarify a stored fact

Storage Location

~/Library/Application Support/deepThinkER/memory/
    WATSON.json
    DEEP.json
    NOVA.json
    SAGE.json

Each file is a plain JSON array — human-readable, easily backed up, and trivially portable. There's nothing proprietary about the format.

Memory cap and eviction: When the 200-entry cap is reached, the oldest entry is evicted to make room for the new one. The eviction policy is FIFO by default — but the context-reset summarisation pass will have already promoted the most important old entries into a more persistent form before they age out.
Memory is private. Each character can only read their own memory store. WATSON cannot RECALL from SAGE's store and vice versa. This is by design — it preserves each character's distinct perspective and prevents convergence toward a shared monolithic "knowledge base."
