16 — Privacy & Security

Privacy is not a feature in deepThinkER — it's the baseline. The app was built from the ground up on the principle that your conversations, your data, and your machine are yours. Here's exactly what that means in practice.

The short version: Everything runs locally. Nothing is sent anywhere except when a character explicitly uses [SEARCH:] or [FETCH:]. No telemetry. No cloud API calls. No account required. No data collection of any kind.

Security Architecture

🔒
100% Local Inference All AI processing happens via the bundled Ollama runtime on your own hardware. No model API calls. No OpenAI, Anthropic, or any external AI service.
🛡️
Injection Guard User input is scanned for tool-call tag patterns before injection into the conversation. Prevents prompt injection attacks like [SEARCH: evil query] in user messages.
🚫
Content Filter Configurable keyword category lists with replacements. Applied to both user input and model outputs. Categories and keywords are fully user-defined.
🌐
Domain Whitelist The [FETCH:] tool checks every URL against a user-managed whitelist before making a request. Unconfigured = open. Configured = restricted to your approved list.
📋
Audit Log Every tool call is logged to an append-only NDJSON file. You always have a complete, immutable record of every time a character touched the internet or the filesystem.
🧮
Safe CalcTool The math evaluator does not use eval() or any dynamic code execution. Expressions are parsed and evaluated by a purpose-built expression tree — no injection surface.

What Leaves Your Machine

The only data that ever leaves your machine from deepThinkER:

  • Search queries — the text argument of a [SEARCH: …] call, sent to DuckDuckGo via HTTPS
  • Fetch URLs — the URL argument of a [FETCH: …] call, requested via HTTPS
  • Model downloads — on first launch only, model weights are downloaded from Ollama's model registry

No conversation text. No user persona. No memory entries. No analytics data. No session transcripts. Nothing else.

Sandbox Status

deepThinkER is not sandboxed by the macOS App Sandbox. This is required because the app spawns the Ollama subprocess — macOS App Sandbox prohibits subprocess spawning, and there is no workaround that doesn't fundamentally break the architecture.

The entitlement in Release.entitlements is: com.apple.security.app-sandbox = false, with outbound network connections enabled.

No sandbox, but not reckless. The InjectionGuard, ContentFilter, domain whitelist, and audit log together provide meaningful mitigations. The app writes only to its Application Support directory and the configured workspace path. It does not request access to Documents, Downloads, Photos, or any other sensitive directory.
ShellTool is a stub. The [SHELL: command] tag is defined but disabled in v1.1.0. Even if a character writes it, the interceptor will return a "tool disabled" result. Enabling it in a future release will require an explicit allowlist of permitted commands, configurable in Settings.
