17 — Data Storage

All app data lives in a single root directory in macOS Application Support — deepThinkER never writes to your Documents folder (which triggers a macOS privacy dialog), your Desktop, or anywhere else on your filesystem outside of the Application Support path and your configured workspace directory.

Format Notes

Every data file in deepThinkER uses a human-readable, open format — plain JSON, NDJSON, or Markdown. There are no binary files, no proprietary formats, and no databases. You can open, edit, back up, or migrate any of these files with standard tools.

The audit.ndjson file uses newline-delimited JSON (one JSON object per line) — trivially parseable with jq, Python, or any streaming JSON parser. No proprietary log format, no binary encoding.

Backing up your data: A single cp -R ~/Library/Application\ Support/deepThinkER /path/to/backup is all it takes. Time Machine will also include this directory automatically. Character memories, relationships, and trust scores are all in there.
Migrating between Macs: Copy the entire Application Support directory to the same path on the new machine, install deepThinkER, and all character memories, relationships, trust scores, and settings will be exactly as you left them.
