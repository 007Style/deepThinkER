09 — Autonomous Research Mode

Sometimes you don't want a conversation — you want an investigation. Autonomous Research Mode lets you give the four characters a research question and watch them divide the work, argue about the findings, and synthesise a final report. All while you can still interject, redirect, or just observe.

Research Mode is a structured, multi-phase protocol managed by the ResearchEngine. Each phase has a defined purpose, a time cap, and a specific type of prompt injected to the characters. The engine tracks phase transitions, manages concurrent character output, and at the end compiles everything into a saved Markdown report.

The Four Phases

Phase 01
Gathering
~5 min
A directive is injected to all characters. Each independently researches the topic using SEARCH and FETCH tools. WATSON looks for data. NOVA explores adjacent angles. SAGE hunts for contradictions. DEEP surveys the landscape.
Phase 02
Debating
~3 min
A debate prompt is injected. Characters cross-examine each other's findings. Disagreements surface. SAGE challenges weak evidence. WATSON demands citations. NOVA proposes reframings. DEEP tries to find synthesis.
Phase 03
Synthesising
~2 min
The engine waits for all four to submit a synthesis contribution. Characters write their final positions. The engine collects them. DEEP's synthesis typically provides the structural frame.
Phase 04
Complete
Instant
The ReportGenerator compiles all four synthesis contributions into a structured Markdown report with extracted sources, key findings, and an attributed conclusion. Report saved to disk.

The Research Report

The final report is automatically saved as Markdown with full source attribution. Every URL that appeared in a [SEARCH:] or [FETCH:] call during the session is automatically extracted and listed in the sources section.

~/Library/Application Support/deepThinkER/reports/<session-name>.md

Interacting During Research

Research Mode doesn't lock you out of the conversation. The user input bar remains fully active throughout all phases. You can:

  • Redirect a character's research focus mid-phase
  • Inject a new source or counter-argument into the debate
  • Ask for a status summary at any time
  • Manually advance to the next phase early
Trust is critical in Research Mode. The Gathering phase relies heavily on SEARCH and FETCH calls. Characters with Low trust will be significantly limited in how much they can research — they may fall back to reasoning from prior memory rather than live internet data. For best results, run Research Mode with characters at Mid or High trust.
Launching Research Mode: Access it from the main toolbar → Research Mode button, or via the keyboard shortcut. You'll be prompted for a research question (or topic) and optional context notes. The session name is auto-generated but can be customised before starting.
