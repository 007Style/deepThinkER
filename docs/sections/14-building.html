14 — Building from Source

deepThinkER is a standard Flutter macOS application. If you have Flutter, Xcode, and CocoaPods set up, you can have a debug build running in minutes. The only extra step compared to a typical Flutter project is pulling the bundled Ollama runtime via Git LFS.

Prerequisites

Terminal
$ flutter --version
Flutter 3.x.x • channel stable

$ xcode-select --install # Xcode command line tools

$ sudo gem install cocoapods # macOS plugin deps

$ git lfs install # For bundled Ollama runtime (metallib files)
Git LFS initialized.

Clone & Setup

Terminal
$ git clone https://github.com/007Style/deepThinkER.git
$ cd deepThinkER

# Pull the bundled Ollama runtime (~285 MB of metallib files)
$ git lfs pull

# Install Dart/Flutter dependencies
$ flutter pub get

# Install macOS CocoaPods dependencies
$ cd macos && pod install && cd ..

Run in Debug Mode

Terminal
$ flutter run -d macos
Launching lib/main.dart on macOS in debug mode...
✓ Built build/macos/Build/Products/Debug/deepThinkER.app

Build Release DMG + .app

Terminal
# Standard release build
$ ./scripts/build_dmg.sh

# With a custom version number
$ ./scripts/build_dmg.sh 1.2.0
ArtefactLocationDescription
deepThinkER-v1.1.0-macos.dmgbuild/Installer DMG with drag-to-Applications layout
deepThinkER.appbuild/Standalone app bundle — run from anywhere

Run Tests

Terminal
$ flutter test
00:12 +147: All tests passed!

$ flutter analyze
No issues found!
All tests are pure Dart. No Flutter widget tests needed for the core logic. The 14 test directories under test/core/ cover everything from trust tier transitions to tool call parsing to context window management. They run in milliseconds with no Ollama dependency.
Debug mode and model downloads: Running in debug mode does not bypass the model download step. The first time you run flutter run -d macos, the app will walk you through downloading all models exactly as it would in a production install.
