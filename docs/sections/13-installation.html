13 — Installation

deepThinkER ships as a standard macOS application — no terminal commands, no package manager, no separate runtime to install. The Ollama inference engine is bundled inside the app. You just drag it to Applications and launch it.

Install from DMG (Recommended)

  1. Download deepThinkER-v1.1.0-macos.dmg from the Releases page
  2. Open the DMG — a window appears with the deepThinkER icon and an Applications folder alias
  3. Drag deepThinkER.app onto the Applications folder alias
  4. Eject the DMG
  5. Launch deepThinkER from Applications (or Spotlight)
  6. On first launch, the app downloads the four AI models (~22.5 GB total). Progress bars show per-model download status. Grab a coffee ☕ — this takes a few minutes on a typical broadband connection and only ever happens once.
Gatekeeper note: If macOS shows "deepThinkER.app cannot be opened because it is from an unidentified developer" — right-click (or Control-click) the app in Finder and choose Open, then click Open in the dialog. This override is saved permanently; you'll never be asked again.
RAM warning: If your Mac has less than 20 GB of free RAM when deepThinkER launches, the Resource Gate screen will show a live RAM gauge and explain why. Running with insufficient RAM will cause models to swap to disk, which is extremely slow and may cause timeouts. Close memory-hungry applications before launching.
Standalone .app: The release also includes a standalone deepThinkER.app that can be run directly from anywhere — a Downloads folder, an external drive, or a project directory — without installing to Applications.
