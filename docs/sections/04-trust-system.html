04 — The Trust System

Internet access in deepThinkER is not a switch you flip once. It's a living score — continuously earned, slowly decayed, and instantly impacted by behaviour. Every character starts at 50 points and their score evolves throughout every session, carrying over to the next.

This isn't just a rate limiter in disguise. Trust is a genuine game mechanic: characters who behave responsibly — staying engaged, not flooding the network, using searches purposefully — accumulate privilege over time. Characters who overreach get penalised. And a character who has been a good citizen across multiple sessions starts the next one with a meaningful advantage.

How Trust Changes

Event Delta Why
Conversation is active (per minute) +1.0 Steady gain for staying engaged and participating
Natural decay (per minute) −0.5 Trust erodes slightly if not actively maintained
Network access toggled back ON +5.0 Reward for regaining the privilege
Network access toggled OFF −15.0 Significant penalty — losing access is a red flag
Rate limit violation −2.0 Over-searching is a misuse of the privilege
Trust persists between sessions. Scores are saved to ~/Library/Application Support/deepThinkER/trust.json at the end of every session. A character who has been a responsible internet citizen across multiple conversations starts the next one with that history intact.

Rate Limiting

The rate limiter enforces two independent ceilings simultaneously:

  • Per-character limit — derived from the character's current trust tier (1, 3, or 5 searches/minute)
  • Global ceiling — configurable cap across all four characters combined (default: 10 searches/minute). Adjustable in Settings → Network.

Both limits use a sliding-window algorithm — not a fixed-clock reset. This prevents bursting at the top of each minute. Rate limit violations are logged to the audit log with full context (character, tool, timestamp, score impact).

Disabling Network Access

Network access can be toggled per-character in the Startup Config screen or in Settings → Network at any point during a session. Toggling it off applies the −15 trust penalty immediately — so it's not a free "pause" button. Toggling it back on rewards the character with +5 trust to help them rebuild.

Want a fully offline session? Simply turn off network access for all four characters in the Startup Config screen before starting. The characters will still have full access to memory, tools, calculations, and image analysis — they just won't reach the internet. All the personality, none of the latency.
