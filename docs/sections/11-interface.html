11 — Interface Overview

deepThinkER's interface is built for watching something happen. The main screen is a live 2×2 grid of AI panels, each streaming in real time, each with its own status indicators, token counter, mood display, and internet activity badge. Everything you need to understand what's happening is visible at a glance.

Quadrant Header Details

Each character's panel header packs in everything you need to know at a glance: the character name and colour, current model, current mood emoji, live token counter, and — when active — the ● LIVE internet badge. Click the badge to expand the latest search result inline.

The User Input Bar

The input bar at the bottom of the main screen is always active. Type a message and press Enter (or Shift+Enter for a newline). Your message is injected into every character's context simultaneously — they all see it and can respond. The 📎 button opens an image picker for vision analysis via the ImageTool. The ⚙ button on the right side of the bar opens quick settings without leaving the main view.

Accessibility: deepThinkER includes a high-contrast mode, reduced motion mode, and font size scaling — all accessible in Settings → Display. The app respects macOS system accessibility preferences and supports full keyboard navigation.
