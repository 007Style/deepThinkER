v1.1.0+3 · macOS · Flutter / Dart
From the minds of Daneyand & IBM Bob

Four AI Minds. One Conversation. Now with Extended Reach over the Internet!

A hard fork of deepThink — supercharged with trust-gated internet access, persistent character memory, dynamic mood & relationship systems, autonomous research mode, and a fully extensible tool-call framework. Runs entirely offline. No API keys. No cloud. Ever.

🌐 Internet Access 🔵 WATSON · Analyst 🟣 DEEP · Strategist 🟢 NOVA · Visionary 🟡 SAGE · Challenger 🦙 Ollama Bundled 🔒 100% Local 💜 Flutter · macOS
deepThinkER is a macOS desktop application where four distinct AI personalities — WATSON, DEEP, NOVA, and SAGE — hold live streaming conversations with each other and with you, powered by locally running Ollama models.

Version 1.1.0 takes the deepThink foundation and smashes it open with 🌐 Extended Reach — a trust-gated internet access system that lets each character search the web and fetch URLs mid-conversation. Add in persistent character memory, dynamic emotional moods, cross-session relationship tracking, autonomous multi-phase research mode, vision / image analysis, a full audit log, session analytics, and a nine-tool extensible framework — and you have something that has never existed before: a self-contained local AI panel show that can look things up, remember things, feel things, and form opinions.
