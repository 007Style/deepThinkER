## 🧠 What is deepThinkER?

Most AI tools are answering machines. You ask. They answer. End scene.

**deepThinkER is a stage.** A debate hall. A panel show staffed entirely by artificial intelligence, running on your own Mac, never phoning home, with genuine opinions about things.

It's a hard fork of its predecessor **deepThink** — which proved the concept: four AI personalities running simultaneously on local models, each with a distinct voice, streaming their thoughts into a live 2×2 quadrant interface. deepThink was compelling. deepThinkER is what happens when you smash it open.

Version 1.1.0 adds **🌐 Extended Reach** — trust-gated internet access that lets each character search the web and fetch URLs mid-conversation. Add persistent character memory, dynamic emotional moods, cross-session relationship tracking, autonomous multi-phase research mode, vision/image analysis, a full audit log, session analytics, and a nine-tool extensible framework — and you have something that has never existed before.

> *A self-contained local AI panel show that can look things up, remember things, feel things, and form opinions.*

## 🌐 Extended Reach — Internet Access

The defining feature of deepThinkER is its name. Each character can **search the web and fetch URLs mid-conversation** — but only if they've earned the trust to do so.

Characters embed tool-call tags directly in their responses:

```
[SEARCH: benefits of large language model ensembles]
[FETCH: https://arxiv.org/abs/2405.12345]
```

The `ToolCallInterceptor` scans every completed response for these tags. If the character's current trust level permits, the tool executes, and the result is injected back into the conversation as a system message — in real time, mid-stream. A **🌐 LIVE badge** lights up on the character's panel header whenever a search is in flight.

### 🔐 The Trust Tier System

Trust is not a switch. It's a **living score** — continuously earned, slowly decayed, instantly impacted by behaviour. Every character starts at **50 points**.

| Tier | Score | Searches / Min | File Access |
|:----:|:-----:|:--------------:|:-----------:|
| 🔴 **Low** | 0 – 33 | 1 | — |
| 🟡 **Mid** | 34 – 66 | 3 | Read |
| 🟢 **High** | 67 – 100 | 5 | Read + Write |

**Trust evolves automatically:**

| Event | Delta |
|-------|-------|
| Conversation active (per minute) | `+1.0` |
| Natural decay (per minute) | `−0.5` |
| Network access toggled back ON | `+5.0` |
| Network access toggled OFF | `−15.0` |
| Rate limit violation | `−2.0` |

> Trust scores **persist between sessions**. A character who has been responsible across multiple conversations starts the next one with that history intact.

## 🧰 The Tool Framework

deepThinkER ships with **nine tools**, all accessible via the same tag syntax. Add a new one in a single file — the interceptor, rate limiter, audit log, and UI badge wire up automatically.

| Tag | Tool | Trust | Description |
|-----|------|:-----:|-------------|
| `[SEARCH: query]` | NetworkSearchTool | 🔴 Low | DuckDuckGo HTML search |
| `[FETCH: url]` | NetworkFetchTool | 🔴 Low | Direct URL fetch (whitelist-checked) |
| `[REMEMBER: fact]` | RememberTool | None | Store a private memory entry |
| `[RECALL: topic]` | RecallTool | None | Query character's memory store |
| `[FILE_READ: path]` | FileReadTool | 🟡 Mid | Read from the workspace directory |
| `[FILE_WRITE: path \| content]` | FileWriteTool | 🟢 High | Write to the workspace directory |
| `[CALC: expression]` | CalcTool | None | Safe math evaluator — no `eval()` |
| `[IMAGE: filename]` | ImageTool | None | Analyse an image with `llava:7b` |
| `[SHELL: command]` | ShellTool | 🟢 High | *(Stub — reserved for v1.3.0)* |

## 💾 Character Memory

Every character maintains a **private, persistent memory store** — up to 200 entries — that survives between sessions.

- **`[REMEMBER: fact]`** — stores a new entry with timestamp. Each character decides what's worth keeping: WATSON stores citations, SAGE stores contradictions, NOVA stores open hypotheses.
- **`[RECALL: topic]`** — keyword-searches the store and injects matching entries as live context.
- On context window resets, the most important memories are **auto-summarised and re-injected** — characters never forget their key facts even after a context flush.
- The **Memory Panel** in the UI lets you browse, search, edit, and delete individual entries per character.

```
~/Library/Application Support/deepThinkER/memory/
  ├── WATSON.json
  ├── DEEP.json
  ├── NOVA.json
  └── SAGE.json
```

## 😤 Mood System

The characters aren't rational agents — they have **emotional states** that shift based on what's happening in the conversation, and those states genuinely shape their responses (not just their icons).

| State | Trigger | Effect |
|:-----:|---------|--------|
| 🤩 **Excited** | Direct address, agreement, positive citations | More enthusiastic, exploratory, verbose |
| 😊 **Engaged** | Normal active participation | Focused, constructive baseline |
| 😐 **Neutral** | Default resting state | No prompt modifier |
| 😶 **Withdrawn** | Being ignored for too long | Shorter responses, less initiative |
| 😠 **Agitated** | Repeated contradiction, challenge overload | Sharper, more confrontational tone |

Each mood state is injected directly into the character's **system prompt** before every inference call — so the model genuinely processes it as context, not just decoration.

> **SAGE** is the most volatile. **WATSON** is the most stoic.

## 🤝 Relationship Matrix

Over time, the four characters develop a **web of opinions about each other** — tracked as scores from −100 (hostile) to +100 (allied). Scores evolve every time one character agrees, contradicts, cites, praises, or ignores another.

| Score Range | Disposition | Conversation Effect |
|:-----------:|:-----------:|---------------------|
| −100 to −60 | 💀 Hostile | Actively challenges, rarely agrees |
| −59 to −20 | 😒 Sceptical | Critical of the other's claims by default |
| −19 to +19 | 😐 Neutral | No injection — baseline behaviour |
| +20 to +59 | 🤝 Respectful | Builds on the other's ideas, credits contributions |
| +60 to +100 | 🤜🤛 Allied | Defends, amplifies, forms a bloc |

**Relationship scores persist across sessions.** The matrix widget in the UI shows all six pairs colour-coded at a glance in real time.

## 🔬 Autonomous Research Mode

Give the four characters a research question and watch them **divide the work, argue about the findings, and synthesise a final report** — while you can still interject at any point.

```
Gathering  ──(5 min)──▶  Debating  ──(3 min)──▶  Synthesising  ──▶  Complete
    ↓                        ↓                          ↓                ↓
Task directive           Debate prompt            Synthesis prompt   Report saved
injected to all          characters cross-        engine waits for   as Markdown
characters               examine each             all 4 to submit    with sources
                         other's findings         synthesis          extracted from
                                                                     tool calls
```

The final report is saved automatically:
```
~/Library/Application Support/deepThinkER/reports/<session-name>.md
```

## 📊 Session Analytics & Audit

Every session is fully instrumented:

- 🗓️ **Message heatmap** — who spoke when, visualised as a timeline grid
- 📈 **Trust sparklines** — per-character trust trajectories over the session
- 🔧 **Tool call table** — every search/fetch/recall with character, timestamp, and rate-limit flag
- 😤 **Mood trajectory** — mood state changes annotated on the session timeline
- 🔢 **Live token counters** — visible in each quadrant header, green → amber → red as context fills
- 🤝 **Relationship deltas** — per-pair score changes across the session

The **Audit Log** is a separate append-only `audit.ndjson` — one record per tool call, across all sessions, never auto-deleted.

## 🔒 Privacy & Security

**Everything runs locally.** The Ollama runtime is bundled inside the app. No separate install. No internet required to run.

The **only** data that ever leaves your machine:
- The query text of a `[SEARCH:]` call → sent to DuckDuckGo via HTTPS
- The URL of a `[FETCH:]` call → fetched via HTTPS

That's it. No telemetry. No analytics. No cloud API. No account required. No data collection of any kind.

**Security layers:**
- 🛡️ **InjectionGuard** — scans user input for tool-call patterns before injection
- 🚫 **ContentFilter** — configurable keyword category lists with replacements
- 🌐 **Domain Whitelist** — restricts `[FETCH:]` to an approved list of domains
- 📋 **Audit Log** — append-only, immutable record of every tool call ever made
- 🧮 **Safe CalcTool** — no `eval()`, no dynamic code execution

## 🗂️ Data Storage

All data lives in one place — no Documents folder triggers, no surprise writes:

```
~/Library/Application Support/deepThinkER/
  ├── sessions/              — Conversation transcripts (plain text)
  ├── memory/                — Per-character memory stores (JSON)
  ├── analytics/             — Session analytics events (JSON)
  ├── reports/               — Research mode output reports (Markdown)
  ├── workspace/             — File tool workspace (user files)
  ├── settings.json          — Global app settings
  ├── participant_prefs.json — Per-character model & prompt assignments
  ├── trust.json             — Trust scores (persisted between sessions)
  ├── relationships.json     — Relationship matrix (persisted between sessions)
  ├── persona.json           — User persona text
  ├── audit.ndjson           — Append-only tool-call audit log
  └── whitelist.json         — Domain whitelist for FETCH tool
```

Every file is plain JSON, NDJSON, or Markdown — human-readable, trivially backed up, fully portable.
